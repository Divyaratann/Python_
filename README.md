# 🐍 Python Basics – Learning Repository

Welcome to my **Python Basics** repository! This repository contains Python programs and practice examples created while learning Python programming.

The goal of this repository is to build a strong foundation in Python by understanding basic syntax, variables, loops, strings, and built-in functions through practical examples.

## 📚 Topics Covered

### 1. 🔤 String Operations (`simple.py`)

- String declaration and printing
- `upper()` – Convert text to uppercase
- `lower()` – Convert text to lowercase
- `find()` – Find the position of a substring
- `replace()` – Replace parts of a string
- Checking whether a substring exists in a string

### 2. 🔁 Loops and Range (`adv.py`)

- Using the `range()` function
- Generating sequences of numbers
- Understanding `while` loops
- Using loop counters
- Incrementing variables
- Printing patterns using string multiplication
- Executing statements after a loop

## ⚙️ Getting Started

### Prerequisites

Install Python on your computer from the official website:

https://www.python.org/downloads/

### Clone the Repository

```bash
git clone https://github.com/Divyaratann/python-basic.git
```

### Navigate to the Project Folder

```bash
cd python-basic
```

### Run the Python Programs

Run the string operations program:

```bash
python simple.py
```

Run the loops and range program:

```bash
python adv.py
```

## 💻 Example Code

### String Methods

```python
name = "divyaratann"

print(name.upper())
print(name.lower())
print(name.find("ark"))
print(name.replace("div", "ark"))
```

### While Loop

```python
i = 1

while i <= 5:
    print(i)
    i += 1

print("End of while loop")
```
